## 计算范围

- 目标：为攻击基础分支提供词条收益比较，并为**具名技能/具名命中段**提供可回放的实测拟合。它不是已证实的任意游戏动作最终公式。
- 可复用的直接公式包括攻击基础、破甲/专攻、防御、已知乘区、暴击/穿刺函数、最终固定项和保底。主动技能的专属基础值、内部倍率和说明值含义不因页面出现“自定义系数”而自动视为已证实。
- “自定义技能系数”不是通用主动技能公式开关：它只允许在具名动作、具名命中段、伤害类型、目标数、攻防快照、Buff/状态、事件标签与策略假设均绑定时，保存为**经验有效系数**。它可以吸收同一快照中尚未拆开的动作内部项，不能被称为游戏内部裸系数，也不能跨快照复用。
- 技能增强/技能抵挡只能作为显式的候选“技能等级项”使用。资料第 7 页称技能增强只放大“技能等级 * 120”项，第 16 页又以【已被录屏数据支持】标注“平 A 也吃技能增强”；对任意具体技能/普攻的适用性仍需该动作自己的实测。
- 普通攻击系数不能静默假定为 1；`1x` 只可用于属性收益比较的比例基准，不能被当作真实跳字。
- 带技能系数、技能等级或主动技能倍率的动作必须使用该技能/该段的专属已验证公式，或绑定到同一攻防快照的经验有效系数；不得从其他动作继承。
- 资料第 14/16 页（录屏支持）给出战士“巨剑斩（普攻）”三段系数 `0.0974 / 0.097 / 0.259`，三段各自独立随机；这些是资料明确覆盖的具体段，不能推广为所有普攻或主动技能的默认系数。
- 资料第 9 页（3.14 完整代入示例）显示“巨剑斩第一段（系数 0.0974，技能 15 级）”的普通一击约 `325`，它由“攻击基础部分（191.5）+ 技能等级部分（297.5）= 489 基础伤害”再乘约 `0.525` 得到。这证明该示例动作存在“技能系数 × 技能等级 × 120 × 技能增强”项，不证明所有动作都使用同一说明值口径。
- 目标类型必须显式选择：普通怪物、精英、首领、玩家、建筑。对怪物使用怪物专攻/专防与怪物压制/抵抗的对应子项；对玩家使用途径专攻/专防与途径压制/抵抗。建筑的常规主链、事件、跨类与条件乘区尚未验证，因此在没有建筑专属证据前，建筑的绝对跳字与经验校准应禁用，而非沿用玩家规则。

## 资料直接公式与条件边界

### 完整结算管线

第二份资料给出了标准玩家伤害技能的完整管线。下式是**资料的完整结构**，不是本产品已对所有具名动作实现或确认的通用绝对公式。攻击基础分支可用于收益比较；具名主动技能只有在有该动作的直接证据，或绑定同一快照的经验校准时，才可启用系数与等级项。普通攻击也不能擅自设为 `1x`。第 16 页的录屏结论称平 A 也受技能增强影响，但尚未给出其精确系数和结算阶段，必须作为独立实验分支处理。

```text
基础伤害 =
  技能系数 * max(攻击随机值 + 破甲差 + 专攻差, 0) * 防御倍率
  + 技能系数 * 技能等级 * 120 * 技能增强倍率

结算伤害 =
  基础伤害
  * 压制倍率 * 增伤倍率 * 加深倍率
  * 暴击倍率 * 格挡倍率
  * 跨类倍率 * 弱点倍率 * 目标数系数 * 怪物修正
  + (最终伤害增强 - 目标最终伤害抵挡)

最终伤害 = max(结算伤害, 基础伤害 * 0.005, 1)
显示跳字 = 最终伤害四舍五入到整数
```

原资料明确：最终伤害增强/抵挡在所有乘法之后相加，因此暴击和格挡都不放大或削减这一个固定项。伤害先扣护盾，再扣生命。跨类、弱点、目标数和怪物修正只在对应的伤害类型、目标类别、目标数与情境数据已知时纳入绝对分支。目标数已有分段公式：`实际命中数 ≤ 技能满伤目标数` 时为 `1`，超过时为 `max(技能满伤目标数 / 实际命中数, 0.08)`；范围/多目标动作缺少“技能满伤目标数”或实际命中计数时仍不能把该项默认为 `1x`。

### 结果口径标准

计算器的结果必须使用以下五种不同名称，不能把它们合并成“伤害”：

- **推荐期望伤害（未取整）**：以攻击区间中点与选定事件策略计算的词条比较模型；只使用压制、增伤、加深等推荐公式规定的乘区，**省略跨类、弱点、目标数和怪物修正**，且不把各分支保底、显示取整、护盾或生命扣除混入其中。它用于属性收益比较，不代表一次跳字。
- **概率加权的单次最终伤害（未取整，可选）**：若用户显式选择事件顺序策略，分别计算普通/暴击/格挡分支的最终保底后，再按该策略的概率加权。它与推荐期望伤害不同；策略未选时不得输出，策略已选时必须标为推断而非已证实服务器顺序。
- **攻击中点条件下的单次最终伤害（未取整）**：固定为普通、暴击或格挡事件时的理论分支结果。它仍然使用攻击中点，因此不是服务器随机取值后的精确一击。
- **预计显示跳字**：对上述单次最终伤害执行最终四舍五入假设后的整数。实测时应按实际发生事件对照普通、暴击或格挡分支；攻击随机值应为区间内整数，不应把连续小数范围写成跳字范围。
- **实测盾损与实测生命损失**：资料只确认最终伤害先扣护盾再扣生命，尚未给出护盾吸收、溢出和精确取整公式。因此两项只能由实验记录，不能由当前模型自动推导。

每一条记录还必须包含“攻击方标识 → 目标标识”“动作名 / 命中段 / 伤害类型”“受影响目标数”“事件标签”“事件策略（如用了概率）”“测试目的”“唯一改动”“比较口径”和固定条件。这样才能解释这次数值是由谁对谁造成的什么伤害，以及测试想验证什么。

### 攻击与防御

- 物理攻击说明给出的攻击基础值范围是 `3575-4006`。资料定义单击为区间内随机整数；端点是否包含、分布是否均匀、各阶段何时取整仍待验证。中点只适用于比较模型，校准与跳字范围必须枚举整数攻击值。
- 固定物理破防 `F` 与忽视物理防御百分比 `p` 的顺序已由原文确认：百分比效果后于固定值效果生效。第二份资料给出直接公式：`effectiveDefense = max(targetDefense - F, 0) * (1 - p)`。该模型的已验证输入域为 `0% ≤ p ≤ 100%`；超出范围不能静默产生负有效防御。
- 防御和破防只作用于攻击基础值，不作用于技能基础值。防御减伤的直接公式为：`reduction = clamp(effectiveDefense * 0.85 / (effectiveDefense + combatLevel * 31.68), 0.25, 0.80)`；`defenseMultiplier = 1 - reduction`。因此防御倍率范围为 `0.20-0.75`。
- 所有按等级放大的公式使用攻防双方较小的战斗等级。战斗等级不是角色等级；映射应作为表数据维护，不能线性外推。

### 破甲与护甲

设攻击方破甲为 `P`，防御方护甲为 `H`。第二份资料将破甲差定义为直接加到攻击随机值的有符号数：

```text
armorDelta = (P - H) / 3,       H <= P
armorDelta = 2 * P - H,         P <= H / 4
armorDelta = (P - H) * 2 / 3,   其他情况
```

它允许小数和负数，不能提前取整。例：`P=108`、`H=146` 时，`armorDelta=-25.3`。等号归属由这份公式明确；服务器的中间取整位置仍需控制变量测试。

### 暴击、暴伤、穿刺与格挡

- 令 `L` 为双方较小战斗等级，`k = 1.12 * L`；当 `L > 45` 时，`k = 0.48 * (L - 45) + 50.4`。
- 暴击差 `c = sourceCrit - targetAntiCrit`；`critRate = clamp((2*c + 45*k) / (c + 180*k), 0.05, 0.75)`。前提是 `c + 180k > 0`；分母为零或负数时资料未定义函数，不能在夹断后伪装成有效概率。
- 穿刺差 `r = sourcePierce - targetBlock`；`pierceRate = clamp((1.5*r + 135*k) / (r + 180*k), 0.25, 1)`；`blockRate = 1 - pierceRate`。同样要求 `r + 180k > 0`。
- 暴伤倍率为 `clamp(sourceCritDamage - targetCritDamageReduction, 1.25, 2.5)`；非暴击倍率为 `1`。资料显示面板百分比应按小数录入，例如 `154% = 1.54`。
- 格挡命中时核心伤害只受 `30%`，最终伤害增强不受格挡影响。资料将“先判格挡、再判暴击”标为【推断】，因此概率加权模型必须公开并要求选择事件顺序策略，不能把它静默当作已证实服务器规则。已标注为普通/暴击/格挡的样本可各自对照分支，但不因此验证事件顺序；未识别事件绝不能自动按普通样本处理。

### 伤害修正层

以下是三组文案明确区分的独立乘区，不能合并为一个“总增伤”字段：

- 增伤 <-> 减伤。
- 伤害加深 <-> 伤害减免。
- 途径压制 <-> 途径抵抗，资料列为玩家/建筑的对应项；建筑是否能沿用其余常规事件与条件乘区仍未验证。

第二份资料给出直接公式：

```text
suppressionMultiplier = campBaseMultiplier * max(0, 1 + sourceSuppression - targetResistance)
increaseMultiplier = max(0, 1 + comboBonus + sourceDamageIncrease - targetDamageReduction)
deepeningMultiplier = max(0, 1 + sourceDamageDeepening - targetDamageMitigation)
crossTypeMultiplier = max(0, 1 + sourceCrossTypeIncrease - targetCrossTypeImmunity)
weaknessMultiplier = 1 + targetWeakness
monsterCorrection = (1 + targetBossWeakness) * sourceAttackCorrection * targetDefenseCorrection
```

阵营基础倍率表尚未恢复；木桩实验可暂用 `1`，但必须以“实验假设 `1x`”显式显示，不能把未知事实默认为中性。跨类需要伤害类型、目标类别和双方对应输入；弱点要求目标弱点输入（已知域不低于 `-100%`）；怪物修正需要首领弱点、攻防修正与目标情境，且不适用于玩家/建筑。缺任一条件时应显示“未建模/禁用”，而不是擅自假设。

资料直接给出“目标数系数”分段规则：实际命中数不超过该技能的满伤目标数时为 `1`，超过时为 `技能满伤目标数 ÷ 实际命中数`，最低 `0.08`。单体动作可以把“实际命中数 = 1、满伤目标数 = 1”作为其快照条件，**不能**据此推导其它动作的满伤目标数。范围、多目标、弹射、分摊和额外命中动作必须记录实际命中数和该技能的满伤目标数；缺任一项时绝对伤害与经验校准应禁用。

最终伤害增强与最终伤害抵挡是点数词条（示例均为 `54`）。第二份资料将固定项定义为 `sourceFinalDamageBonus - targetFinalDamageResistance`，且在全部乘法之后相加；随后取 `max(结算伤害, 基础伤害 * 0.005, 1)` 并四舍五入显示。该顺序已有资料公式支持，但仍建议以低伤害控制变量实验验证服务器的精确取整点。

## 控制变量测试顺序

每条记录必须固定双方等级、目标、目标类型、攻击动作、所有 Buff、装备与天赋；保存攻击方和目标方完整面板快照。不要只记录一个变化后的词条。

1. 普通攻击系数与技能增强：在禁用其他额外词条的条件下，确认普通攻击是否确实对应 `1`，并做两组仅改变技能增强的平 A 实验，定位其系数和阶段；不要以主动技能公式替代。每条样本需标注动作/命中段和事件。
2. 攻击范围：收集足够的非格挡、非暴击命中，确认 `3575-4006` 的端点、随机分布、显示均值和取整。
3. 固定破防与百分比忽视：使用同一高防目标，分别单改 `F` 和 `p`。验证 `(D-F)*(1-p)`、固定破防的零下限及防御倍率夹断。
4. 破甲/护甲：让 `P` 跨过 `H/4` 与 `H`，每个临界点测 `-1/0/+1`，并增加连续 1 点测试服务器取整位置。
5. 穿刺/格挡：按组统计至少 `300-500` 次；接近边界时建议约 `1000` 次。验证穿刺率函数与格挡是否先于暴击。
6. 暴击/抗暴与暴伤：剔除格挡样本或压低格挡，分别改变暴击、抗暴、暴伤、暴伤减免，验证概率、倍率和上下限。
7. 百分比层：分别只开增伤、伤害加深、途径压制，再做两两组合，验证独立乘区与阵营基础倍率；另测跨类、弱点及怪物修正，并在每次实验记录伤害类型、目标类别和情境。
8. 最终伤害点数与保底：在两个不同的前置倍率下测试 `+1`、`+54` 与对应抵挡，并测低伤害场景，定位固定项、保底和取整先后。
9. 途径/怪物条件：分别攻击普通怪物、精英、玩家、建筑，验证子项选择及 `max(0, source-target)` 零下限。建筑应单列测试，未验证前不要复用玩家事件或条件乘区。
10. 五维：一次只加 1 点五维，记录哪些原始面板变化；确认转换函数前，不将当前 `83 -> 150` 等样本当成比例公式。
11. 目标数：对同一具名范围技能、同一命中段，分别命中 1/2/3… 个有效目标，记录每个目标的跳字、目标角色、分摊/弹射状态及所有 Buff；验证满伤目标数和实际命中计数语义，不能以一个动作的满伤目标数预测另一个动作。

# 2.2 交付版动作公式记录

2.2 交付版将动作公式接入完整动作结算。属性收益比较仍使用无系数基准；完整动作结算在当前动作、命中段和完整快照下接入技能项及全部条件层，不再提供独立的测试模式。

公式图片给出的候选为：

```text
技能增强倍率 = clamp(1 + 0.025 × (技能增强 − 技能抵挡) ÷ 战斗等级, 0.05, 2.5)
技能等级项 = 技能系数 × 技能等级 × 120 × 技能增强倍率
基础伤害 = 技能系数 × (攻击随机值 + 破甲差 + 专攻差) × 防御倍率 + 技能等级项
```

交付链的 `技能增强` 与 `技能抵挡` 取独立输入；`技能等级` 和 `动作系数` 取当前动作记录。技能说明面板数字仍只作为证据记录，不自动反推系数。动作系数只对当前动作、命中段和完整快照有效，不跨动作推广。

完整动作结算要求显式确认全部适用条件层：阵营基础倍率、跨类倍率、弱点倍率、目标数，以及对怪物目标适用的怪物修正。通过后才显示完整最终分支；未确认的条件层不会被静默当作 `1x`。事件顺序未知时仍只显示带标签的普通/暴击/格挡最终分支，不伪造概率期望。
